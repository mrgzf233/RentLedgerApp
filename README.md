# Rent Ledger & Lease Management System App

## Overview

A Java-based property management and rent ledger system inspired by real-world landlord-tenant office workflows.

This project was designed to help organize rent records, lease renewals, tenant balances, and landlord communication in a more efficient digital format.

---

# Core Features

## Rent Ledger Management

Tracks and organizes tenant rent payment information including:

- Monthly rent amount
- Amount paid by tenant
- Payment method (Cash/Check)
- Payment date
- Remaining balance for that month
- Total balance

---

## Commercial Lease Options

Additional optional fields for commercial properties:

- Late fees (For now adding 5% after the 1st day of the month)
- Water/Sewer fees(future updates)

These fields can be toggled depending on the property type.

### Example
- Residential tenant → standard rent fields only
- Commercial tenant → includes late fees and utility-related charges(future update)

---

## Lease & Renewal Tracking

Store and manage lease renewal information digitally in an organized database system.

Tracked information includes:

- Building address
- Apartment number
- Tenant name
- Legal rent
- Preferential rent
- Lease start date
- Lease expiration date
- Renewal lease status checklist
- Landlord's contact info

---

## Renewal Reminder Workflow

Designed to help monitor lease expiration timelines and organize renewal preparation.

The system allows:

- Identify leases expiring within upcoming months
- Tracks renewal lease progress
- Organizes landlord communication
- Reduce manual searching through physical folders/paperwork

---

## Export & Document Storage

Planned in the future:

- Exporting rent ledger forms
- Saving generated forms into the database
- Reprinting documents when needed

---

# Purpose of the Project

This project was inspired by hands-on experience working with landlord-tenant office documentation and lease management workflows.

The goal is to simplify repetitive administrative tasks by organizing tenant, lease, and rent information into a searchable and structured system.
